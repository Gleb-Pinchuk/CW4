# CW4

Курсовой проект по созданию веб-приложения для управления рассылками сообщений на Django.

## Функциональность

- Управление получателями рассылок (клиентами)
- Управление сообщениями для рассылок
- Управление рассылками с возможностью запуска
- Отслеживание попыток отправки и статистика
- Система аутентификации и авторизации
- Разграничение прав доступа (пользователи и менеджеры)
- Кеширование для повышения производительности

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Gleb-Pinchuk/CW4.git
cd mailing_service
```

2. Создание виртуального окружения
python -m venv venv
venv\Scripts\activate

3. Установка зависимостей
pip install -r requirements.txt
